# Screenshots

The main README shows these images. Save each one here with exactly this file name (PNG).

## Before you start

1. Make the browser window wide (about 1440 px) and use the dark theme (⋮ → Settings).
2. Follow "Replay mode for a demo" in the main README: register the samples, train and activate the models.
3. On **Replay / demo**, start **Port scan → DDoS** at **30×** and let it play for about a minute.
4. Take the shots below while it plays. Afterwards, **Clear replay data** if you want a clean database.
