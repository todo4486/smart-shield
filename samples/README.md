# SAMPLE data: synthetic, for trying the app only

**Every file in this folder is synthetic.** None of it is real network traffic, real attacks or real measurements.
The files are generated by `python -m scripts.make_sample_data` with fixed seeds, so they can be reproduced exactly.
When you import them, keep "SAMPLE (synthetic)" in the source or dataset name so they stay labelled inside the app.

| File | Use it in | What it shows |
| --- | --- | --- |
| `SAMPLE_telemetry_7days_synthetic.csv` | ML Laboratory → Data sources → **Import telemetry** | See the notes below |
| `SAMPLE_telemetry_with_errors_synthetic.csv` | **Import telemetry** | Each row demonstrates a validation rule; see below |
| `SAMPLE_intrusion_train_day_synthetic.csv` | **Register intrusion dataset**, then Smart Shield models → Train | See the notes below |
| `SAMPLE_intrusion_test_day_synthetic.csv` | **Register intrusion dataset**, then Security Center → Run detection | A different "day" the model never trained on: about 92% recall at about 1% false positives |

**`SAMPLE_telemetry_7days_synthetic.csv`**

- **Interfaces:** `campus-uplink` and `lab-link`, sampled every 5 minutes from Friday to the following Thursday 15:00 UTC.
- **campus-uplink** has a 1 Gbit/s configured capacity, weekday peaks, and a Tuesday-evening backup spike. The file ends at a busy peak, so forecasts show high or critical risk and raise congestion alerts.
- **lab-link** has no capacity, so utilization stays unavailable for it. Forecasting utilization on lab-link is refused, which is correct.

**`SAMPLE_telemetry_with_errors_synthetic.csv`**

- **Rejected rows:** a non-ISO timestamp, a missing timezone, a negative rate, a ratio above 1, a non-number, and a row with no measurements. Each is rejected with its reason.
- **Kept rows:** a missing latency value is kept as *partial*. Of two rows with the same timestamp, the first is kept.

**`SAMPLE_intrusion_train_day_synthetic.csv`**

- **Format:** 12,000 flows in CIC-IDS2017 format. Headers have leading spaces, IPs and timestamps are included, and a few `Flow Bytes/s` values are `Infinity`.
- **Labels:** BENIGN, DDoS, DoS Hulk, PortScan and FTP-Patator.
- **Difficulty:** 15% of attacks imitate benign traffic and there is 1% label noise, so scores are realistic rather than perfect.

**Suggested import settings**

- Telemetry: the default options work, because timestamps already end in `Z`.
- Intrusion files: dates are day-first. Use a UTC offset of `-3` if you want CIC-IDS2017-style local time; `0` also works.
